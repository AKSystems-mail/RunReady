# RunReady 🏃

AI-powered running route generator built with **Flutter**.

Find great running routes near you — powered by Gemini and Google Maps.

## Quick Start

```bash
cd run_ready
cp lib/config/env.dart.example lib/config/env.dart
# Edit env.dart with your API keys
flutter run
```

See [run_ready/README.md](run_ready/README.md) for full setup instructions.
